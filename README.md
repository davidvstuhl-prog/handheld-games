# Handheld Games 🎮

Games for my homemade Raspberry Pi calculator handheld: Pi Zero 2 W,
2.8" 480×640 screen, and 10 buttons (D-pad, A, B, L, R, Start, Select).

| Folder | What's inside |
|---|---|
| [`balloon-blitz/`](balloon-blitz) | **Balloon Blitz**, a balloon-popping tower defense game (like Bloons TD 6) |
| [`pc-tester/`](pc-tester) | A handheld emulator, so you can test the games on a computer |
| [`ti84-ce/`](ti84-ce) | **Balloon Blitz CE**, a smaller version for the TI-84 Plus CE calculator (C) |

## Quick start (on a computer)

```
pip install pygame
cd pc-tester
python handheld_emulator.py
```
